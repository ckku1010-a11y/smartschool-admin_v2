💡 3 Golden Rules for New Teachers Using This System

1. Morning Sick Leave before 07:30: Click the red "⚡ 1-Click Morning Sick Leave" button on the Main Menu. The system automatically attaches your subject's default 40-minute Learning Pack so you can rest immediately.
2. Lesson Swaps vs Cover Balance: If you swap a lesson reciprocally with a colleague (e.g. for a competition trip), choose "Reciprocal Lesson Swap". It will not deduct from your Net Cover workload balance.
3. Supervising a Cover Class: Open Module 3 (Start Cover Lesson) on the classroom computer. Take roll call with 1 click, project the 40-minute timer, and let students complete the 7-minute Exit Check before the bell.
